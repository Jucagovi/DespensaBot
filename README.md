# DespensaBot

Aplicación mobile-first en tiempo real para la gestión de la cesta de la compra y la despensa compartida.

## Características

- **Sincronización en tiempo real:** integración con Supabase para reflejar cambios al instante en todos los dispositivos conectados.
- **Modo Comprando:** visualización de productos en una sola línea ordenada alfabéticamente con logotipos de comercios y filtro rápido por tienda.
- **Modo Haciendo lista:** administración del catálogo de la despensa, asignación de tienda y cantidad con popup táctil, renombrado y eliminación.
- **Theming:** interfaz basada en PrimeReact con tema Nano y conmutador de modo claro y oscuro persistente.
